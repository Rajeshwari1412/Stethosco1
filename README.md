# 🩺 STETHOSCO (v29 FINAL) — Unified Pan-India Medical Ecosystem Platform

> **STETHOSCO** is an all-in-one unified healthcare and medical ecosystem platform designed for India, connecting **Doctors, Patients, Hospitals, Medical Students, NEET Aspirants, Diagnostic Labs, Pharmacies, Blood Banks, and Ambulances** across **36 States & UTs** and **632+ Cities**.

---

## 🌟 Key Platform Capabilities & Portals

1. **🩺 Doctor Portal:** AI-powered job matching, digital EMR prescription management, doctor schedule manager, and consultation earnings dashboard.
2. **🎯 NEET Rank & Seat Predictor:** AI-assisted UG (NEET-UG / 720) & PG (NEET-PG / 800) rank bands, percentile estimation, and confirmation probability across 96+ top medical colleges (AIIMS, MAMC, CMC Vellore, JIPMER, KEM, etc.).
3. **🏥 Hospital Portal:** NABH credential verification, department management, multi-role doctor/staff job postings, and applicant tracking.
4. **🫀 Patient Portal:** AI Symptom Checker, digital health records, STETHOSCO Premium membership, insurance empanelment, and shareable QR profile.
5. **🚑 Emergency Ambulance Dispatch:** 24x7 GPS emergency dispatch, multi-operator aggregator network (BLS/ALS/ICU ambulances), and nearest hospital routing.
6. **🩸 Blood Bank & Life Saver Network:** Donor finder across all blood groups (A+, B+, O+, AB+, Bombay Blood Group) by area, town, and pincode, plus critical emergency calls.
7. **💪 Health & Cardio Tracker:** Daily steps and calorie ring gauges, live vitals (BP, HR, SpO2, Blood Sugar), BMI calculator, daily hydration counter, and sleep tracker.
8. **🎓 Student Corner & Internships:** Internships database, MBBS/Nursing college directory, verified profiles, and sponsor-a-medico educational funding.
9. **🔬 Diagnostic Labs & 💊 Pharmacy:** Vendor product/test catalogues, digital test booking, doorstep lab sample collection, and prescription medicine cart.
10. **✈️ Medical Travel & Tourism:** JCI/NABH hospital packages, cost comparison calculators, travel assistance, and multilingual support.
11. **💚 Jeevandan Organ Donation:** Organ pledge registry, NOTTO/THOA compliance, and recipient waiting list management.
12. **🛠️ Central Admin Panel:** Live revenue analytics, hospital/institute credential approvals, verification queues, and system audit logs.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rajeshwari1412/Stethosco.git
   cd Stethosco
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
